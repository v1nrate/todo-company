# Corporate ToDo

## Описание
Веб-приложение для управления задачами сотрудников внутри компании.

## Стек
- Python
- Django
- PostgreSQL
- HTML, CSS, JavaScript

## Функциональность
- Регистрация и авторизация пользователей
- Роли (сотрудник / руководитель)
- CRUD операции с задачами
- Фильтрация и сортировка
- Комментарии и загрузка файлов
- Telegram-уведомления

## Запуск проекта
```bash
git clone https://github.com/v1nrate/todo-company
cd todo-company
pip install -r requirements.txt
python manage.py runserver
```
